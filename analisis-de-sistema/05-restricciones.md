# Restricciones del Sistema

## Lista de Restricciones

| ID | Restricción | Descripción |
| :--- | :--- | :--- |
| **RC01** | Aplicación web | El sistema debe desarrollarse como una plataforma web accesible desde navegadores web de escritorio. |
| **RC02** | Control de versiones | El código fuente debe gestionarse utilizando Git y mantenerse en un repositorio compartido. |
| **RC03** | Stack tecnológico | El backend debe desarrollarse en PHP con el framework Laravel, el frontend con Blade y Bootstrap, y la base de datos en MySQL. |
| **RC04** | Firma digital con DNIe | La firma digital debe realizarse obligatoriamente utilizando el DNI electrónico (DNIe) y un lector de tarjetas inteligentes compatible conectado al equipo del Administrador/Encargado. |
| **RC05** | Servicio de notificaciones | El sistema debe integrarse con la API/servicio de WhatsApp para enviar notificaciones sobre el estado de las solicitudes al ciudadano. |
| **RC06** | Integraciones externas fuera de alcance | El proyecto no contempla la integración directa en tiempo real con todos los sistemas gubernamentales externos ni la modificación de registros oficiales de otras instituciones. |
| **RC07** | Procesos judiciales fuera de alcance | El sistema no contempla la gestión automatizada de procesos judiciales relacionados con las actas. |
| **RC08** | Pasarela de pagos | El proyecto no incluye integración con pasarelas de pago reales para el cobro de tasas administrativas. |
