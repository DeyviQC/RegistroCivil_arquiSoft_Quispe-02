# Imagen de portada

La portada usa `public/img/municipalidad/plaza-portada-limpia.png`, una versión editada con IA a partir de `plaza-distrital.png`. La original se conserva. La edición retira el texto, escudo flotante e iconos de redes incrustados, y mejora la presentación. No es una nueva fotografía documental; los detalles reconstruidos por IA pueden variar respecto de la toma original.

Herramienta: image_gen integrada, modo edición. Prompt empleado: limpiar la misma fotografía para una portada municipal; retirar únicamente las superposiciones de texto, escudo y redes; reconstruir cielo y pavimento; mejorar compresión, claridad y balance natural de color; preservar iglesia, monumento, plaza, banderas, árboles y perspectiva; no agregar edificios, personas, objetos, textos ni marcas. Composición panorámica 16:7, alta resolución.

El escudo oficial se mantiene como elemento independiente en el encabezado. La capa de contraste pertenece al CSS y mantiene el texto HTML legible.
